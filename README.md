🧭 Rotas na Prática — Desafio React Router
Projeto educacional desenvolvido com React, Vite e React Router para praticar a navegação entre páginas em uma aplicação de página única (SPA), componentes compartilhados, rotas dinâmicas, carregamento sob demanda e tratamento de páginas inexistentes.
🎯 Objetivo
Aprender a configurar rotas em React e construir um pequeno site multipáginas, com navegação fluida e estrutura organizada. Ao final do desafio, você deverá saber:
- Configurar o BrowserRouter, Routes e Route.
- Navegar com Link e NavLink, sem recarregar a página.
- Criar páginas independentes e reutilizar componentes de layout.
- Renderizar rotas filhas usando Outlet.
- Carregar páginas sob demanda com lazy() e Suspense.
- Ler parâmetros de URL com useParams().
- Tratar rotas inválidas com uma página 404.
🛠️ Tecnologias
- React 19 — componentes e interface.
- React Router 7 (react-router) — navegação e rotas.
- Vite 7 — ambiente de desenvolvimento e build.
- CSS — layout e estilização responsiva.
